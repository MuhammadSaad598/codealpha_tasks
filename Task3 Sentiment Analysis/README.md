# Amazon Alexa Reviews Sentiment Analysis

## 📌 Project Overview

This project was completed as **Task 3** of the **CodeAlpha Data Analytics Internship**.

The objective of this project is to analyze customer reviews of Amazon Alexa products using Natural Language Processing (NLP). Reviews are classified into **Positive**, **Negative**, and **Neutral** sentiments. Various visualizations are created to understand customer opinions and generate business insights.

---

## 🎯 Objectives

- Analyze customer review text.
- Perform sentiment classification using NLP.
- Visualize customer sentiment.
- Understand public opinion and customer satisfaction.
- Generate business recommendations based on customer feedback.

---

## 📂 Dataset Information

**Dataset Name:** Amazon Alexa Reviews Dataset

**Source:** Kaggle

**Number of Records:** 3150

**Number of Features:** 5

### Dataset Columns

- Rating
- Date
- Variation
- Verified_Reviews
- Feedback
