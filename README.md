# Titanic Exploratory Data Analysis (EDA)


## Project Overview

This project was completed as part of the **CodeAlpha Data Analytics Internship**. The objective is to perform **Exploratory Data Analysis (EDA)** on the Titanic Passenger Dataset to understand passenger characteristics, identify survival patterns, clean the dataset, and generate meaningful insights using Python.

---

## Objectives

* Explore the dataset structure.
* Understand variables and data types.
* Handle missing values.
* Perform data cleaning.
* Visualize the dataset.
* Identify trends, patterns, and anomalies.
* Test hypotheses using statistics and visualizations.
* Detect data quality issues.
* Draw meaningful conclusions.

---

## Dataset

* **Dataset Name:** Titanic Passenger Dataset
* **Total Records:** 891
* **Total Features:** 12

## Key Findings

* Female passengers had a higher survival rate than male passengers.
* First Class passengers survived more than Second and Third Class passengers.
* Higher ticket fares were generally associated with higher survival rates.
* Most passengers were between 20 and 40 years old.
* Missing values in the Age and Embarked columns were handled successfully.
* The Cabin column was removed due to excessive missing values.
* Several outliers were identified in the Fare column.
