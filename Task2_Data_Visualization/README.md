# CodeAlpha Data Analytics Internship

## Task 2: Data Visualization


## Project Overview
This project focuses on transforming raw business data into meaningful visualizations using Python. The Superstore dataset was analyzed to identify trends, patterns, and business insights through charts and graphs. The visualizations help support data-driven decision-making.


## Objectives
- Transform raw data into visual formats.
- Create charts using Matplotlib and Seaborn.
- Identify sales and profit trends.
- Analyze customer segments and regional performance.
- Build a professional data visualization portfolio.


## Dataset
- **Dataset Name:** Superstore Dataset
- **Total Records:** 9,994
- **Total Columns:** 21

### Important Columns
- Order Date
- Ship Date
- Category
- Sub-Category
- Segment
- Region
- State
- City
- Sales
- Profit
- Quantity
- Discount

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Visualizations Created
- Sales by Category
- Profit by Category
- Sales by Region
- Profit by Region
- Sales by Customer Segment
- Monthly Sales Trend
- Top 10 States by Sales
- Top 10 Cities by Sales
- Discount vs Profit
- Correlation Heatmap


## Key Insights
- Technology products generated the highest sales.
- Consumer customers contributed the highest revenue.
- The West region achieved strong sales performance.
- Large discounts often reduced profit.
- Sales varied across different months, indicating seasonal trends.
